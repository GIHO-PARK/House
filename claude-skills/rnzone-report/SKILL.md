# RN존 듀얼전략 리포트

차트박사의 RN존(라운드넘버존) 매매법을 두 개의 다리로 운용하는 전략의 자동 스크리너.

- **다리 1 트레이딩**: 레버리지 ETF(거래대금 100만$/일 이상 자동 편입, ~33종) 자체 차트의 RN존 신호. 목표 +20% / 2차 후 본절 / 기간청산 42일
- **다리 1' 본주 트레이딩**: 듀얼코어 6종목(AMD ARM PLTR GOOGL TSLA NVDA) 본주 차트. 기간청산 63일
- **다리 2 주배당 적립**: 본주 신호 발생 시 WeeklyPay ETF(AMDW ARMW PLTW GOOW TSLW NVDW) 매수 후 영구 보유. 분배금은 매주 섹터 모멘텀 1위 섹터에 재투자

## 사용법

리포트 요청을 받으면 **스크립트를 실행하고 출력 전문을 그대로 보여준다** (요약·생략 금지):

```bash
python scripts/rnzone_report.py
```

- Windows는 `python`, macOS/Linux는 `python3`. 표준 라이브러리만 사용, 설치 패키지 없음.
- 약 40회 API 조회로 1~2분 소요. 타임아웃 180초 이상.
- 실패 시 사실대로 알리고 재시도. 결과를 지어내지 않는다.

## 리포트 읽는 법

| 섹션 | 의미 |
|---|---|
| 💰 자본 배분 | 총 자본(CAPITAL_KRW, 기본 5,000만원)을 트레이딩:주배당 = TRADE_RATIO 비율(기본 70:30)로 나누고, 트레이딩은 7슬롯 균등 → 슬롯당 금액을 1:2:3 비중으로 분할, 주배당은 듀얼코어 6종목 균등 → 종목당 상한. 환율은 야후 KRW=X 실시간 조회 |
| 📌 오늘 할 일 | 직전 거래일 신규 신호. 매수 지시엔 목표가·기간한도·진입금액($/원) 동봉, 본주 신호엔 주배당 적립 지시 동반 |
| 🆕 신규 진입 대상 | (NEW_INVESTOR_MODE=True 기본값, 실보유 없는 사용자 기준) 이미 차수가 성립된 종목을 **오늘 종가를 진입가**로 삼아 오늘 일괄 진입 시 목표가·기간청산을 재계산. 과거 평단 기반 손익/매도·본절·기간청산 청산 안내는 표시 안 함. 실제 보유분을 추적하려면 스크립트 상단 `NEW_INVESTOR_MODE = False`로 바꾸면 기존 '💼 보유 중'(평단·손익·본절가) 표시로 전환 |
| 💰 주배당 적립 | 이번 주 분배금 재투자 대상 섹터(60일 모멘텀 1위) |
| 🔥 임박 / ⚡ 매수 대기 | 상단선·매수선까지 거리. 본주 행엔 주배당 예상가 |
| 🧭 유니버스 점검 | 오늘의 레버리지 편입 명단(거래대금 자동 필터) — 실행할 때마다 매일 재평가됨 |

## 전략 요약 (배경)

RN존 = 1~2,000$의 고정 라운드넘버 20개 선. 상단선 4% 이내 터치 = 조건성립 → 아래 선에서 1차(비중1) → -20%에서 2차(비중2) → 아래 RN선에서 3차(비중3). 트레이딩은 평단 +20% 매도·본절·기간청산으로 회전, 주배당은 영구 보유하며 매주 분배금 수취. 가격 손절 없음 — 출구는 기간·자격(시총/지수/사업 훼손 시 매도)·회로차단기(-30%). 상세·백테스트 근거·한계는 [references/method.md](references/method.md) 참고. 사용자가 원리를 물으면 이 파일을 읽고 답한다.

## 정기 자동 실행 (구독)

첫 리포트 후 **"매일 아침 11시에 자동으로 받으시겠어요?"라고 먼저 제안**한다. 동의하면:
1. [references/routine-prompt.md](references/routine-prompt.md)의 프롬프트를 **그대로**(수정 금지) 사용해
2. 스케줄 기능(schedule 스킬/RemoteTrigger)으로 클라우드 루틴 생성 — 기본 cron `0 2 * * *`(한국 11시), 이름 "RN존 듀얼전략 아침 리포트", 모델 claude-sonnet-5, 도구 Bash/Read/Write/WebFetch
3. **⚠️ 네트워크 허용 필수**: 클라우드 기본 환경은 외부 접속이 차단되어 야후 조회가 403으로 실패한다. 사용자에게 안내할 것 — claude.ai/code에서 해당 루틴 편집(✏️) → 환경 선택 → "+ 환경 추가" → 네트워크 액세스 "사용자 정의" → 허용 도메인에 `query1.finance.yahoo.com`, `query2.finance.yahoo.com`, `finance.yahoo.com` 3줄 입력 → 환경 생성 → 저장. 이 설정 없이는 루틴이 데이터를 못 가져온다.
4. 등록 후 안내: 다음 실행 시각, 결과 위치(claude.ai/code/routines), PC 꺼져도 실행됨
5. 스케줄 기능이 없으면 솔직히 알리고 수동 실행 안내

## 커스터마이징

`scripts/rnzone_report.py` 상단 상수: TOUCH/BUYZ/SELL, HOLD_LEV(42)/HOLD_STK(63), LIQ_MIN(유니버스 기준), LEVS(레버리지 후보), DUAL(듀얼코어), SECTORS(섹터 구분), NEW_INVESTOR_MODE(신규 진입 재계산 여부, 기본 True), CAPITAL_KRW(총 자본, 기본 5,000만원), TRADE_RATIO(트레이딩:주배당 배분 비율, 기본 0.7). 종목 추가 시 야후 티커 규칙(BRK.B→BRK-B) 주의. 사용자가 자본금이나 배분 비율을 바꾸면 CAPITAL_KRW/TRADE_RATIO를 수정할 것 — 임의로 가정하지 말고 반드시 사용자에게 확인.

## 주의사항 (사용자에게 전달)

- 자동 계산 참고자료이며 투자 자문이 아니다. 판단과 책임은 본인에게 있다.
- 백테스트는 상승장 표본(2년) 기준 — 약세장 성적은 검증되지 않았다. 소액 포워드 테스트로 시작할 것.
- 레버리지 ETF는 변동성·잠식이 크고, 주배당 ETF는 분배락으로 가격이 우하향한다(수익은 분배금 포함 총수익으로 볼 것).
- 얇은 ETF는 지정가 주문 필수. 데이터는 일봉 기준이라 장중 실시간은 트레이딩뷰 병행.
