# RN존 듀얼전략 — 로직 상세와 검증 근거

## 출처

- 기법: 유튜브 "차트박사의 주식 이야기" 『미국 RN존 신매매법 통합편』 + 도서 『절대수익 우량주 매매법』(이레미디어, 성경호)
- 전략 설계·백테스트: 2026-08, 2년 일봉 데이터(야후 파이낸스) 기준 자체 검증

## 라운드넘버 20개 가격선 (영상 슬라이드 검증)

- 대호가 11개: 1 / 2 / 5 / 10 / 20 / 50 / 100 / 200 / 500 / 1,000 / 2,000
- 50% 상승가 9개: 3 / 7.5 / 15 / 30 / 75 / 150 / 300 / 750 / 1,500 (1.5는 제외)

## 공통 상태머신 (3단)

1. **조건성립**: 고가 ≥ 상단선×0.96 → 매수선 = 상단선 아래 RN선
2. **1차 매수**: 저가 ≤ 매수선×1.02 (비중 1)
3. **2차 매수**: 저가 ≤ 1차선×0.80 (비중 2)
4. **3차 매수**: 저가 ≤ 매수선 아래 RN선×1.02 (비중 3)
5. **매도**(트레이딩만): 고가 ≥ 평단(금액가중)×1.2 목표 / 2차 이후 평단 회복 시 본절 / 기간청산(레버리지 42일·본주 63일)

## 두 다리의 신호 렌즈가 다른 이유 (백테스트 결론)

| 다리 | 신호 기준 | 근거 |
|---|---|---|
| 트레이딩 | **레버리지 ETF 자체 차트** | 증폭된 차트가 신호를 7배 자주 생성(2년 122건 vs 17건). 빈도가 수익. 검증 +133~136% (자본 1,500만) |
| 주배당 적립 | **본주 차트** | 주배당 ETF 차트는 분배락으로 우하향 왜곡 → RN존 부적합. 본주 트리거가 레버리지 트리거보다 효율 +14%p(37.6% vs 23.5%). 깊이가 수익 |

## 핵심 백테스트 결론 (2년, 상승장 표본)

1. **트레이딩 최적 대상 = 레버리지 ETF** (승률 71%, 122건, 실현손실 0 — 단 상승장 표본임을 유의. S&P500 전체로 확장 시 승률 68% 유지되나 손실 사이클 발생)
2. **유니버스는 "상위 N 랭킹 컷"이 아니라 "거래대금 기준선(100만$/일) 통과 전부"** — 랭킹 컷은 신흥 강자(SMCX류)의 초기 사이클을 놓침(-400만). 갱신 주기는 빠를수록 유리(주간이 분기 대비 +360만) → **실제 구현은 리포트 실행 때마다 매일 재평가**. 단, 후보 목록(LEVS)에 없는 신규 상장 ETF는 자동 발굴되지 않으므로 분기에 한 번 수동 추가 필요
3. **분배금은 10가지 재투자 방식 중 9개가 현금 수취에 패배.** 유일하게 통한 것이 **섹터 모멘텀 재투자**(60일 수익률 1위 섹터에 균등, +42.7% vs 현금 +37.6%) — 사용자의 기존 투자 프레임과 일치해 채택
4. **가격 손절은 유해** (-50% 손절 테스트: 바닥 매도 기계화, +13.4%→+8.0%). 출구는 ①기간 ②자격 상실(시총 이탈·지수 제외·사업 훼손·ETF 상폐) ③회로차단기(다리 전체 -30% 시 신규 중단)
5. **자격 심사**: 시총 메가캡 + 이익 내는 실물 사업 + ETF 유동성 1M$/일. 자산 프록시(MSTR류)는 적립 제외 — 이 필터 하나가 수익률 +21%→+30%를 만듦
6. 종합 검증: 3다리 합산 +2,496만 / 최대 동시 투입 2,300만 / **2년 +108.5%** (세전, 체결가 근사, 생존편향 일부 포함)

## 듀얼코어 6종목의 의미

AMD·ARM·PLTR·GOOGL·TSLA·NVDA는 ①자격 통과 ②주배당 ETF 유동성 통과 ③유동성 좋은 레버리지 ETF 존재 — 세 조건을 모두 만족하는 교집합. 본주 신호 하나로 본주 트레이딩+주배당 적립이 동시 발동하고, 대응 레버리지 ETF(AMDL·ARMG·PLTU·GGLL·TSLL·NVDL)는 자체 차트로 별도 신호를 낸다.

## 주배당(WeeklyPay) ETF 특성

- 본주 주간 수익률의 120% 추적 + 매주 분배(분배락 매주 발생 → 가격 우하향이 정상, 성과는 총수익 기준)
- 실측 베타 1.16~1.20. 예상가 = ETF현재가×(1+베타×본주하락률), 하락폭 25%↑는 참고치
- 검증된 티커: AMDW ARMW PLTW GOOW TSLW NVDW (+ AAPW AMZW AVGW BABW BRKW COIW COSW HOOW METW MSFW MSTW NFLW UBEW UNHW)
